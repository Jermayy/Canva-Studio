# Security Policy

## Reporting a vulnerability

Please don't open a public issue. Report it privately through GitHub: **Security → Report a vulnerability** on this repository ([direct link](https://github.com/Jermayy/canvas-studio/security/advisories/new)). Include details and steps to reproduce.

You'll get an acknowledgement within 5 business days and updates as it's investigated.

Please don't test against other people's accounts or data. Use your own account, or run the app locally (no Supabase project needed, see the README).

## Supported versions

| Version                                | Supported |
| -------------------------------------- | --------- |
| latest (production deployment, `main`) | ✅        |
